# 人狼イベント管理システム（最小版）

## 現在入っている機能

- トップページ
- イベント一覧
- イベント詳細
- イベント画像
- 先着型 / 抽選型の設定
- 管理画面
- イベント登録
- イベント削除
- SQLiteによる保存
- スマホ / PC向けレスポンシブ表示

## 起動方法（Mac）

ターミナルでこのフォルダへ移動してから、

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python3 app.py
```

起動後、ブラウザで

http://127.0.0.1:5000/

を開いてください。

管理画面：

http://127.0.0.1:5000/admin
